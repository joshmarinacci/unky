A small macOS browser

My Browser

A browser prototype built with Tauri and Rust, with native website tabs, bookmarks, and browsing history.

Download for macOS

Version 0.1.0 · Apple Silicon

First launch on macOS

This early build is not notarized, so macOS may ask you to approve it before opening.

How to open the app
  1. Try opening My Browser once. If macOS says it cannot verify the developer, choose Done.
  2. Open System Settings → Privacy & Security, scroll to Security, then choose Open Anyway for My Browser.
  3. Review the prompt and choose Open to confirm.

Only approve the app if you trust this download. If macOS says it will damage your computer, do not override that warning. See Apple’s instructions.
